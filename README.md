\# ScamSathi – SMS Scam Detection System



\## Project Description

ScamSathi is an educational AI/ML project that analyzes SMS messages and classifies them into three categories:

\- Safe

\- Spam

\- Scam



It uses a machine learning model and a Streamlit web interface.



\## Technologies Used

\- Python

\- Machine Learning

\- Scikit-learn

\- Pandas

\- Streamlit

\- Joblib



\## Main Features

\- SMS message classification

\- Prediction probability display

\- Risk indication

\- Message analysis history

\- Simple web interface



\## Installation



1\. Install Python 3.11.

2\. Open a terminal in the project folder.

3\. Install the required packages:



&#x20;  pip install -r requirements.txt



\## Run the Project



Run this command:



&#x20;  python -m streamlit run scamsathi\_app\_v4.py



Open the local URL displayed in the terminal.



\## Model File

The trained model is stored in:



models/scam\_detector\_v4.pkl



\## Important Note

This project is an educational prototype.

Its predictions may be incorrect. Always verify suspicious messages

through official sources. Do not rely on this system alone for security decisions.
